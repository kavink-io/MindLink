# MinkLink

MinkLink is a privacy-first, anonymous student collaboration platform designed to enhance cognitive growth and study habits without compromising user identity. 

## Features

- **Anonymous Collaboration**: Connect with peers without revealing your identity.
- **Real-time Synchronization**: Powered by Socket.IO for seamless, real-time room syncing and communication.
- **Encrypted Chat**: Keep conversations secure with end-to-end encryption.
- **Pomodoro Timers**: Built-in timers to maintain focus during study sessions.
- **AI Study Assistance**: Smart AI tools to help with learning and understanding complex topics.
- **Mind Battles**: Interactive challenges to test and improve cognitive abilities.
- **Cognitive Growth Dashboard**: Track your study progress and cognitive improvements over time.
- **Dark Neon Glassmorphic UI**: A premium, high-performance user interface designed for focus and aesthetics.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Zustand, Framer Motion, Recharts
- **Backend**: Node.js, Express, Socket.IO
- **Encryption**: TweetNaCl

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd MinkLink
   ```

2. Install dependencies for the frontend and backend:
   ```bash
   npm install
   ```

3. Start the development server (frontend):
   ```bash
   npm run dev
   ```

4. For the backend server, navigate to the `server` directory and start it:
   ```bash
   cd server
   npm install
   npm run dev
   ```
